💻 로컬 Gradio 웹 앱 실행 안내 (설치 위치: e:\Agent\ComfyUI\chatterbox)

로컬 머신에서 직접 Gradio UI를 띄워 실시간으로 음성을 합성할 수 있습니다.

1. 다국어 TTS 웹앱 실행:
python multilingual_app.py
2. Turbo TTS 웹앱 실행 (감정/추임새 태그 지원):
python gradio_tts_turbo_app.py
3. 표준 TTS 웹앱 실행:
python gradio_tts_app.py
4. Voice Conversion (음성 변환) 웹앱 실행:
python gradio_vc_app.py
