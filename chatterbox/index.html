  • 초저지연 1스텝 디코더
  • [laugh], [chuckle], [sigh] 네이티브 지원

Turbo 데모 열기
📋 코랩에서 1분 만에 끝내는 실행 순서
1

환경 설치 및 GPU 세션 자동 초기화

첫 번째 셀을 실행하면 Chatterbox와 Qwen3-TTS가 자동으로 설치되며 세션이 1회 재시작됩니다.

!pip install -q chatterbox-tts "setuptools<81" qwen-tts soundfile
2

내 목소리 10초~30초 파일 업로드

파일 선택 창에 조용한 환경에서 녹음된 목소리(mp3/wav/m4a)를 업로드하면 24kHz 규격으로 자동 최적화됩니다.

3

원하는 파이프라인(더빙 or 나레이션) 클릭

Chatterbox 다국어 글로벌 더빙 또는 Qwen3 한국어 나레이션 셀의 재생 버튼(▶)만 누르면 결과 음성이 브라우저에 바로 재생됩니다.

4

결과물 일괄 ZIP 자동 다운로드

생성된 모든 언어의 음성 파일이 my_global_voice_pack.zip 파일로 묶여 내 PC로 자동 저장됩니다.

💻 로컬 PC 실행 (오프라인/단독 사용 시)

다국어 TTS 웹앱

로컬 머신(E:\Agent\ComfyUI\chatterbox)에서 직접 웹 인터페이스를 구동합니다.

python multilingual_app.py
로컬 앱 열기 (localhost:7860)

Turbo 감정 태그 웹앱

웃음, 기침 등 추임새 버튼이 포함된 Turbo 전용 웹앱을 로컬에서 엽니다.

python gradio_tts_turbo_app.py
로컬 앱 열기 (localhost:7861)
